## Что внутри
- `index.html` — весь сайт (один файл: HTML+CSS+JS)
- `images/` — твои фото (лого без фона, принты, худи, кошелёк)

## Пароль админки
Пароль по умолчанию: `NlxAKIQX@KsuRWD8`
Открыть админку: кнопка-невидимка в правом нижнем углу страницы (почти не видна специально).

**Поменять пароль** — два способа:
1. Через саму админку: Admin → Settings → "Новый пароль админки" → Save Settings.
2. Вручную в коде: найди в `index.html` строку
   `const DEFAULT_ADMIN_HASH = '...'`
   и замени хэш на SHA-256 своего пароля (можно посчитать в любом "sha256 online generator" — просто вбей пароль и вставь результат).

⚠️ **Честно про защиту.** Сайт полностью статический (без сервера), поэтому пароль проверяется прямо в браузере пользователя. Хэш не даёт прочитать пароль "в лоб" через код страницы, но технически подкованный человек всё равно может открыть консоль разработчика и вызвать функцию открытия админки напрямую, в обход пароля. Это предел любого бесплатного статического хостинга (GitHub Pages, Netlify free и т.п.) — настоящая защита админки требует сервера с базой данных и это уже не бесплатно. Для сайта-витрины с ручными заказами через Telegram/эквайринг — риск невысокий, но не выдавай эту страницу за "безопасную CRM".

## Как менять фото/логотип/товары
- Админ-панель (Products → Add/Delete) — работает, но сохраняет изменения **только в твоём браузере** (localStorage). Другие посетители сайта изменений не увидят, пока ты не перенесёшь их в сам файл.
- Чтобы изменения увидели все посетители: Admin → Settings → "Export JSON" → открой `index.html` в текстовом редакторе → найди `let products = [...]` → замени на экспортированные данные → загрузи файл обратно на GitHub.
- Чтобы заменить картинку товара — просто перезалей файл с таким же именем в папку `images/` на GitHub (например `images/scam-tee.jpg`) — старое фото заменится автоматически.
- Логотип без фона лежит в `images/logo-transparent.png`.

## Валюта
- Все цены хранятся в рублях (поле `price` в коде).
- Доллар/USDT считается по курсу `usdRateRub` (по умолчанию 90). Меняется в Admin → Settings → "Курс USD → RUB".
- Галочка "подгружать автоматически" пробует взять курс с бесплатного публичного API (`exchangerate-api.com`). Если недоступно — остаётся ручной курс. Это сторонний бесплатный сервис, не от Anthropic и не от тебя — он может отвалиться без предупреждения, поэтому ручной курс — основной и самый надёжный вариант.
- Доставка — фиксированные 777₽, прибавляются при оформлении заказа, показываются в обеих валютах.

## Деплой на GitHub Pages (бесплатный хостинг + бесплатный поддомен)
См. пошаговую карточку в чате. Коротко: создаёшь публичный репозиторий → загружаешь `index.html` и папку `images/` → Settings → Pages → Source: main → сайт появится на `https://твой-юзернейм.github.io/название-репозитория/`.

**Важно про "бесплатный домен":** GitHub даёт бесплатно только поддомен вида `username.github.io`. Полноценный домен типа `kunibog.ru` или `kunibog.com` — это отдельная платная услуга у регистратора (обычно от ~150–1000₽/год в зависимости от зоны), GitHub Pages просто умеет "подключить" уже купленный домен бесплатно. Бесплатного `.ru`/`.com`-домена не существует ни у кого.
